Quick Summary

Use WEBGL mode for 3D primitives, then combine transform, light, and camera for depth. Push/pop keeps each object isolated.

Key Points

  • In WEBGL, origin is the canvas center.
  • Axes: X right, Y down, Z toward viewer.
  • Transform order changes final result.
  • Lighting type strongly affects form readability.
  • Use push/pop for clean multi-object scenes.
